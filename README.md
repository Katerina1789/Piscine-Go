# Piscine Go
[![Zone01](https://img.shields.io/badge/Zone01-Athens-blue?style=for-the-badge)](https://zone01.gr/gr/)

**Foundation bootcamp in Go programming.**

This repository contains my work from the Go Piscine at Zone01 — an intensive, fast‑paced month designed to strengthen problem‑solving along with soft skills and develop a solid understanding of programming fundamentals.

## Structure

```
📁 QUEST 01/          # Shell scripting & Git basics
📁 QUEST 02/          # Loops & ifs
📁 QUEST 03/          # Pointers & string manipulation
📁 QUEST 04/          # Recursion & mathematical functions
📁 QUEST 05/          # Advanced string operations
📁 QUEST 06/          # Program arguments & parameters
📁 QUEST 07/          # Arrays & slices
📁 QUEST 08/          # Structs & file I/O
📁 QUEST 09/          # Higher-order functions
📁 QUEST 11/          # Linked lists
📁 QUEST 12/          # Binary trees
📁 GROUP PROJECTS/    # Collaborative challenges
📁 HACKATHON/         # 24-hour long hackathon == 24 quests
```

## Navigation

Each quest builds upon the previous, progressing from basic syntax to complex data structures.  
This repository showcases the foundational skills developed during that month.

## Purpose

A reference for anyone exploring Go or preparing for a future Piscine and a record of my own growth as an aspiring developer, demonstrating the journey from "Wow, so many colored lines" to "I can actually use Go!".
